# Movie Ticket Booking Website

## Description
A simple Movie Ticket Booking Website developed using HTML, CSS, and JavaScript. Users can search for movies, select seats, and book tickets.

Live webpage:https://abinayasai05-boop.github.io/Movie-ticket-booking-system-/

## Features
- Search movies
- Select seats
- Calculate ticket price
- Confirm booking

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Open `index.html` in a web browser.
2. Select a movie.
3. Choose seats.
4. Click **Confirm Booking**.

## Conclusion
This project demonstrates basic frontend web development concepts using HTML, CSS, and JavaScript.
